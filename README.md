# Digiblox

A fan-made social gaming and creation website inspired by the feel of classic 2016-era creator platforms.

## Run locally

Open `index.html` in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish for free

This project is a static website, so you can host it for free on GitHub Pages:

1. Push the repo to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set source to `main` and folder to `/root`.
5. Save.
6. Your site will publish at:

```text
https://digiblox.github.io/digiblox/
```
